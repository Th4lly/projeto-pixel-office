QUICK START
Choose Game_Ready (1x) or Detail_2x (2x); use one set consistently.
Keep native canvas sizes. The 2x canvases and placement coordinates are doubled.
SCENE_PLACEMENT.json reproduces the matching example using top-left coordinates.
ASSET_INDEX.json lists the image dimensions.
Examples are flat PNG images, not editable engine scenes.

SURFACES AND ALIGNMENT
floor_walnut.png repeats in both axes at 256px (1x) or 512px (2x).
wall_cream_walnut.png is a ready-made 480x240px backdrop (960x480px at 2x).
It combines existing wallpaper and wooden panels; it is not a seamless wall tile.
The wooden panels cover the bottom of the wallpaper.
Place curtains 13px left and 10px above the window at 1x; double this at 2x.

IMPORT
Pixel-styled artwork with anti-aliased edges, not a strict 32x32 tile grid.
Use point/nearest filtering for native-size or integer-scaled display.
Do not mix native 1x/2x sizes.
The example rug is rendered at 88% size; the original rug PNG is unchanged.
Use render_width/render_height in SCENE_PLACEMENT.json for its exact demo size.
Other objects retain their native scale.
No animations, collisions or engine import presets are included.
